## 业务目标与数据

面向中小发行商的候选游戏筛选和排序，用于安排尽调及预算。数据为Steam Store Games截至2019-05-01的单次快照，主表27,075行、18列，另有五张辅助表。

项目是回顾性筛选原型。主标签表示观测热度/参与度，不等同于销量、收入、利润、质量或因果影响。单次快照不能证明属性与发售当天取值相同，也不能提供一致的发售后观察窗口。

## v1.1设计摘要

### 主标签与时间切分

`total_ratings = positive_ratings + negative_ratings`。在完整的有效发行年份组内按pandas `quantile(0.9, interpolation="linear")` 计算切点，`total_ratings >= cutoff` 时 `hit_reviews=1`，其余为0。边界并列全部纳入，不强制每年精确10%；1997–2005等小于30款的早期年份照常标注。

2019发行记录全部排除出模型开发、验证和测试。开发样本24,862款，正类2,500：

| split | 发行年 | 行数 | 正类 | 正类率 |
|---|---|---:|---:|---:|
| train | ≤2016 | 10,345 | 1,046 | 10.1112% |
| validation | 2017 | 6,357 | 637 | 10.0204% |
| final test | 2018 | 8,160 | 817 | 10.0123% |

验证集用于选择参数和阈值，测试集保留到最终评估。禁止随机切分和shuffled CV。正类率接近10%主要由同年分位标签设计决定，不能单凭它判断没有数据或概念漂移。同年比较减少跨年曝光时长差异，不能消除同年内发行月份差异和快照局限。

`release_date` 按UTC解析，非法值强制为 `NaT` 并明确计数记录，不静默删除。日期用于生成月份、季度、星期及月份/星期的sin/cos周期特征。

### 特征边界与历史编码

| 范围 | 字段和要求 |
|---|---|
| 主模型 | 月份/季度/星期及周期编码、english、developer/publisher、platforms、required_age、categories、genres；release_year主要用于标签和切分 |
| 厂商历史 | developer/publisher按`;`拆成多个实体，只使用严格较早发行年份；匹配任一列出实体的历史游戏取并集，同一历史appid只计一次 |
| 历史输出 | `dev_prior_count`、`dev_prior_hit_rate`、`pub_prior_count`、`pub_prior_hit_rate`，次数使用log1p变换 |
| 平滑与回退 | 命中率=(历史并集正类数+10×0.10)/(历史并集游戏数+10)；未见或缺失实体次数为0、命中率为0.10 |
| 仅快照敏感性 | price、achievements、descriptions、requirements、support info、media及其派生特征 |
| 禁止进入X | positive/negative ratings、owners、average/median playtime、SteamSpy tags/社区投票、评价聚合及其派生字段；tag_count同样禁止 |
| 关联用途 | appid/name用于关联和核对；标签、split与关联标识不作为预测变量 |

多实体历史的并集去重是D-023的具体实施约定，记录为 `aggregation="union_prior_games_deduplicated"`，不改写会议原文。所有预处理仅在历史训练数据fit。历史厂商编码限制了所用游戏的发行年份，其命中标签仍来自同一快照，因此不能据此宣称真实预测时点已可获得相同信誉信息。

owners仅作次要有序稳健性结果，不用 `rank(method="first")` 制造源数据未提供的桶内排序。好评率仅作可选质量敏感性结果，须明确最小评价数和阈值；会议未冻结这两个参数，不能把STEP1中的0.80/50直接当成主标准。

### 方法与指标

历史厂商规则 → Logistic Regression → 一个正则化树集成模型（优先XGBoost，环境不允许时Random Forest）。报告Average Precision / PR-AUC、ROC-AUC、Top10% precision/recall/lift，不以accuracy为主；阈值仅在验证集选择。

正式模型与规则基准需使用相同的历史窗口，明确2018评估是否采用包含2017的历史。评分并列须写清处理方式，另外报告未见厂商表现。
